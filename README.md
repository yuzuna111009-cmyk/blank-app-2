# 🧙‍♂️ レポートRPG

Streamlit を利用した、レポート全文を評価して**スコアと称号**を付与する Web アプリケーションです。  
楽しみながら自分のレポートを客観的に確認でき、今日のランキングで他の挑戦者と競うことができます。

---

## 🌐 デモURL

スリープ状態のときは青色の起動ボタンを押して起動してください。  
[レポートRPG を試す](https://your-app-url.streamlit.app/)

---

## 🌟 主な機能

- **レポート評価モード**  
  レポート全文を入力すると AI 風ロジックでスコアを算出し、称号を付与。
- **称号システム**  
  スコアに応じて以下の称号を自動表示：
  - 90以上：🏆 伝説の大賢者  
  - 75以上：🧙 大賢者  
  - 60以上：⚔ 勇者  
  - 40以上：🛡 見習い戦士  
  - それ以下：🐣 初心者
- **今日のランキング表示**  
  今日投稿されたレポートのスコアランキングを確認可能。
- **Supabase 連携**  
  名前・スコア・称号を永続的に保存。アプリ再起動後もデータ保持。
- **簡易操作 UI**  
  名前とレポートを入力 → 評価ボタン → スコア・称号表示。
